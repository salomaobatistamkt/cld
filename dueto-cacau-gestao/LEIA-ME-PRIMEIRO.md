## 🚀 INSTALAÇÃO EM 5 MINUTOS

### 1️⃣ Descompacte

```bash
tar -xzf eliz-bakery-system.tar.gz
cd eliz-bakery-system
```

### 2️⃣ Instale

```bash
npm install
```

### 3️⃣ Execute

```bash
npm run dev
```

### 4️⃣ Acesse

Abra no navegador:
```
http://localhost:3000
```

**Pronto! Sistema rodando localmente** ✅

## 📡 DEPLOY NO VERCEL (Recomendado)

### Se quer colocar online:

1. **Crie conta GitHub** (github.com)
2. **Novo repositório** chamado `eliz-bakery-system`
3. **Push local para GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/SEU-USER/eliz-bakery-system.git
   git push -u origin main
   ```

4. **Acesse vercel.com**
5. Clique **"New Project"** → Selecione repositório → **"Deploy"**
6. Pronto! App rodando em URL permanente 🎉

## 🔥 ATENÇÃO: GÁS

**Campo ESPECIAL que você pediu:**
- Cada receita tem gás em LITROS
- Você mede empiricamente
- Afeta 100% do preço final
- Se ignorar = preço errado!

Como medir:
1. Anote marcador do cilindro
2. Asse uma batelada
3. Anote novo marcador
4. Diferença = litros usados
