✅ PRECIFICAÇÃO (SISTEMA COMPLETO)
   A precificação funciona assim:
   1. Custo de Ingredientes (soma)
   2. Custo de Gás (litros × preço) - CUIDADO: gás por fogão
   3. Custo Total Direto (1+2)
   4. Custo por Unidade (3 ÷ quantidade)
   5. Margem Mão de Obra (4 × margem%)
   6. Custo Operacional (4+5)
   7. Preço Final (6 × (1 + margem lucro))
   
   Alternativas de margem: 30%, 50%, 75%, 100%

✅ CAIXA DA EMPRESA

   • Categorias por tipo
   • Saldo em tempo real

💾 ARMAZENAMENTO
═══════════════════════════════════════════════════════════════════════════════

Os dados são salvos em localStorage (navegador):
• Seguro para um único usuário
• Sem necessidade de servidor
• Perdido se limpar cache (FAÇA BACKUP SEMANAL!)

Backup:
1. DevTools (F12) → Console
2. JSON.stringify(localStorage)
3. Copie e salve em arquivo


🚀 COMO USAR
═══════════════════════════════════════════════════════════════════════════════

LOCAL (Teste):
1. npm install
2. npm run dev
3. Acesse http://localhost:3000

GITHUB + VERCEL (Produção):
1. Crie repositório no GitHub
2. git push para GitHub
3. Acesse vercel.com → Import Repository
4. Deploy automático em 2-3 minutos
5. URL: https://seu-projeto.vercel.app


📊 EXEMPLO DE FLUXO
═══════════════════════════════════════════════════════════════════════════════

1. Configure Preço do Gás (⚙️ em Precificação)
   └─ Consulte sua conta de gás

2. Crie Receita (Pão Francês)
   ├─ Nome, Categoria, Quantidade
   ├─ Gás utilizado: 0.45L (medido empiricamente)
   └─ Ingredientes com custos

3. Veja Preço Sugerido (Precificação)
   └─ R$ 1,43/pão (exemplo)

4. Crie Pedido (Pedidos)
   ├─ Cliente, Data, Itens
   └─ Status: entregue

5. Registre no Caixa (Caixa)
   ├─ Entrada: Venda
   ├─ Saída: Ingredientes
   └─ Saída: Gás

6. Visualize Dashboard
   └─ Veja lucro, margem, tendências
